# Web Application Regression Checklist

- [ ] Registration works with valid data
- [ ] Required-field validation works
- [ ] Invalid email is rejected
- [ ] Password mismatch is rejected
- [ ] Login works with valid credentials
- [ ] Invalid login shows error
- [ ] Logout ends the session
- [ ] Protected pages require authentication
- [ ] Dashboard loads
- [ ] Primary navigation links work
- [ ] Profile changes save
- [ ] Invalid profile data is validated
- [ ] Search returns expected results
- [ ] No-results state is usable
- [ ] Primary buttons have clear labels
- [ ] Error messages are understandable
- [ ] Core pages remain usable after browser resize
